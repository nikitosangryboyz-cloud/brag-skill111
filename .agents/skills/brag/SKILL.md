# /brag

You built it. Now let's brag about it.

## What this skill does

Turns the current project website or app into a short, polished, shareable launch video using Hyperframes. It reads the project code directly, plans a project-specific concept, creates a storyboard, hands off a focused composition brief to Hyperframes, then validates and renders the result.

Read the rest of the workflow from `references/step-1-inspect.md`, `references/step-2-plan.md`, `references/step-3-compose.md`, `references/step-4-deliver.md`, plus `references/audio.md` and `references/tones.md`.

Invocation options: `--tone`, `--format`, `--duration`, `--no-music`, `--no-sfx`, `--title`, `--voice`.

Creative laws: 15–25 seconds, readable text, project-specific visuals, actual UI/copy, no generic SaaS filler, strong first-2-second hook, and humor only when earned by the product.
